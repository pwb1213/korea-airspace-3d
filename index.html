자료와 표현 기준

사용자가 제공한 대한민국 AIP ENR 2.1·2.2·3.1·3.2·5.1·5.2·5.3·5.5와 airspace_final.js의 경계 자료를 사용합니다. 재래식 항공로는 AIP 공시 폭을, RNAV는 사용자가 지정한 모델 폭을 적용했습니다. 원문 구간 제한은 선택 패널에서 확인할 수 있습니다.

ENR 5.1비행금지·제한·위험 ↗ENR 5.2군훈련·경계 공역 ↗ENR 5.3민간훈련·레이저 ↗ENR 5.5초경량 UA 구역 ↗경계 JS제공된 원본 내려받기 ↓ENR 2.1공항 공역 원문 ↗ENR 2.2제주 Class B 원문 ↗ENR 3.1재래식 항공로 원문 ↗ENR 3.2RNAV 항공로 원문 ↗
  • 특수 공역: ENR 5.1의 P·R·위험구역 D, ENR 5.2의 MOA·ACMI·공중급유·HTA·경계구역·ADIZ, ENR 5.3의 CATA·레이저 위험 구역을 구분합니다. 위험구역 D는 ATS Class D가 아닙니다. 초경량 UA는 ENR 5.5의 경계·고도를 적용합니다. 대응 자료가 불완전한 나머지 항목은 평면·위치 정보로 남깁니다.
  • 특수 공역 경계·고도: 제공된 JS의 수평 경계를 AIP 구역 코드와 대조하고, AIP에 공시된 좌표·반경의 수정이 필요한 곳은 원문 범위를 적용했습니다. 고도는 각 PDF의 수직한계를 사용하며, 여러 고도층과 그 사이의 빈 공간을 유지합니다. 선택 패널에서 경계 출처와 보정 내용을 확인할 수 있습니다.
  • UNL: 상한 없는 공역은 원문 상한을 UNL로 보존합니다. 화면에는 선택한 30,000·60,000·100,000 ft까지 입체를 그립니다. 이 설정은 공시 상한을 바꾸지 않으며, FL 800처럼 수치가 있는 상한은 자르지 않습니다.
  • 자료 판본: 특수 공역 ENR 자료에는 2014~2025년의 서로 다른 판본이 포함되어 있습니다. 각 구역의 페이지 날짜를 보존하며, 2026-07-23 항공도는 기존 공항 공역 대조와 A8·A9A·A9B·MOA29의 고도 보완에 사용합니다.
  • 공항 공역: ENR 2.1·2.2의 Class B·C·D 공항 공역만 별도 색상으로 표시합니다. 다각형 내부의 제외 구역과 여러 조각의 경계를 보존합니다. 혼합 등급의 TMA 전체를 공항 등급으로 채우지 않습니다.
  • 연결 공역 합침: 인천·김포 Class B는 하한 고도별로 합쳐 표시합니다. 두 공항의 원문 경계와 고도는 보존하며, 하나만 선택하면 해당 공항 범위만 표시합니다. 다른 공항 공역의 기존 경계와 고도는 유지합니다. 연결 관계는 새로 제공된 2026년 7월 23일 항공도로 확인했습니다.
  • 제주·속초: 제주 B는 ENR 2.2-1에 공시된 비대칭 경계와 고도층을 사용합니다. 양양은 반경 5 NM 전체 원형을 유지하며, 속초에서 양양과 겹치는 부분만 제외해 중첩부를 양양에 배정합니다. 반경과 고도는 ENR 2.1 기준을 유지하고, P518 방향은 추가로 잘라내지 않은 사용자 지정 표시 모델입니다. 업로드한 AIP 판본의 날짜를 보존합니다.
  • 공항 고도 기준: GND·SFC·AGL는 지형 미반영 명목높이로 표시합니다. AGL에 지형 높이를 더한 실제 MSL 고도로 변환한 것이 아닙니다. 원문 기준은 선택 패널에 표시합니다.
  • 항공로 폭: ENR 3.1의 Lateral limits는 전체 폭으로 적용하며 중심선 양쪽에 절반씩 배분합니다. 구간별 폭 변화를 반영합니다.
  • RNAV 모델 폭: 사용자 지정 규칙에 따라 RNAV2는 중심선 좌우 2 NM씩(전체 4 NM), RNAV5는 좌우 5 NM씩(전체 10 NM) 입체로 표시합니다. 현재 업로드 자료의 RNAV 36개 항공로는 모두 RNAV2입니다. 이 폭은 AIP에 공시된 항공로 폭과 구분되는 사용자 모델이며, RNAV 항법 정확도가 법적 공역 폭을 자동으로 정한다는 의미는 아닙니다. 폭이 지정되지 않은 구간만 중심선 수직 단면으로 표시합니다.
  • 고도: MEA를 하한으로 사용합니다. 괄호 안 MOCA는 항공로 하한을 대체하지 않습니다. FL은 기압고도이며 시각화에서는 100 ft 단위의 명목 고도를 미터로 환산합니다. 실제 대기·기압 조건에 따른 기하학적 고도와는 다릅니다.
  • 등급: 항공로는 원문에 공시된 A·D 구간을, 공항 공역은 B·C·D로 명시된 부분을 표시합니다. Class G 및 공시되지 않은 공간은 3D 부피에서 제외합니다. 높이 배율은 시각적 강조이며 원문 수치는 바뀌지 않습니다.
  • 형상: WGS84 좌표에서 구간 중심선과 수직 방향의 좌우 경계로 입체를 구성한 시각화입니다. 지형은 타원체이며 공시 공역 경계의 법적 해석을 대신하지 않습니다.
