# 대한민국 공역 3D — 특수 공역 / 공항 B·C·D / 항공로 A·D

사용자가 제공한 대한민국 AIP ENR 2.1·2.2의 공항 Class B·C·D, ENR 3.1·3.2의 항공로 Class A·D, ENR 5.1·5.2·5.3·5.5와 `airspace_final.js`를 대조한 특수 공역을 표시하는 정적 웹앱입니다.

## 실행

GitHub Pages는 `main` 브랜치의 루트(`/`)에서 제공합니다. 지도·공역 데이터·Cesium 엔진은 이 저장소 안의 정적 파일을 사용하며, ChatGPT에 로그인할 필요가 없습니다. 배경 지도 타일만 OpenStreetMap에서 불러옵니다.


이 저장소의 루트 폴더를 정적 웹 호스팅에 올리거나, `index.html`이 있는 현재 폴더에서 `python -m http.server 8000`을 실행한 후 `http://localhost:8000`을 여세요. 파일을 직접 더블클릭하는 `file://` 실행은 JSON·Cesium Worker 로딩이 제한됩니다. ZIP 다운로드판은 이 파일과 같은 폴더가 앱 루트입니다.

## 검색 노출과 공개 범위

메인 지도와 자료 안내 HTML에 `noindex, nofollow, noarchive`를 적용해 검색엔진의 색인을 제한합니다. 검색 제외를 처리하는 검색엔진이 설정을 읽을 수 있도록 크롤링 자체를 차단하지 않습니다. 이 설정은 접근 제한이 아닙니다. GitHub Pages와 이 저장소는 공개되어 있으며 주소를 아는 사람은 접속할 수 있습니다.

## 화면 조작

처음에는 특수 공역을 표시합니다. 위쪽의 `특수 공역`·`공항 공역`·`항공로` 체크박스로 세 레이어를 독립적으로 켜고 끕니다. 같은 이름의 탭에서 목록과 필터를 전환합니다. 목록의 ↗ 버튼으로 해당 구역에 접근하고, 입체를 클릭하거나 고도층 선택 메뉴에서 원문 고도·출처를 확인하세요. 위험구역 D, 공항 Class D, 항공로 Class D 필터는 서로 독립적입니다.

## 특수 공역 — ENR 5.1·5.2·5.3·5.5 및 항공도

- 총 276개 특수 공역 항목 중 260개 구역을 270개 고도층으로 표시합니다. 제공 ENR 5 항목은 261개, 항공도 보완 항목은 4개이며, 나머지 JS 11개는 대응 자료가 부족해 평면으로 보존합니다. ENR 5에서 경계·고도가 불완전한 5개를 합하면 추가 자료·확인이 필요한 항목은 16개입니다.
- 원본 JS 347개 중 62개는 TMA·CTR·FIR·ATZ·CTA입니다. 나머지 285개를 대조한 결과, ALERT로 기재된 12개가 실제 Class D ATZ/CTR에 대응해 공항 레이어로 재분류했습니다. 신규 ATZ 11곳과 기존 속초로 연결하며, 특수 ALERT 입체로 중복 생성하지 않습니다. 원본 JS와 매핑은 보존합니다.
- UA 48곳은 ENR 5.5(9 JAN 2025)의 경계·고도로 모두 3D화했습니다. 원형 12곳의 반경은 AIP의 기본 단위 km/m를 우선하고, UA62는 개정된 15점 경계를 적용했습니다. UA60·UA62의 운영시간 중 제외 조건은 보존하며, 운영 상태를 모르는 상태에서 영구적인 구멍으로 만들지 않습니다. 목록 선택 시 작은 UA 구역을 볼 수 있도록 더 가까이 접근합니다.
- A8은 SFC–FL140, A9A·A9B는 SFC–3,000 ft AMSL, MOA29는 3,000 ft AGL–FL400으로 2026-07-23 항공도 고도를 적용했습니다. 수평 경계는 위치를 대조한 첨부 JS를 유지합니다.
- P 비행금지, R 비행제한, D 위험, MOA·ACMI·공중급유·HTA 군훈련/작전, ALERT 경계, CATA 민간훈련, 레이저 위험, ADIZ 방공식별, UA 초경량 항목을 유형별로 켜고 끌 수 있습니다. ADIZ는 처음에는 숨깁니다. D 위험구역은 ATS Class D와 별개입니다.
- MOA의 분리된 고도층과 그 사이 공백을 유지합니다. MOA31L의 양양 CTR 제외는 겹치는 명목 고도 범위에만 적용하며, A810은 서울 CTR을 제외합니다. A811 김포 CTR 제외 및 시간·활성 상태에 따른 항공로 제외는 필요한 자료가 부족해 원문 조건을 안내합니다.
- UNL 원문 상한은 보존하며 화면에만 30,000·60,000·100,000 ft 중 표시 높이를 적용합니다. FL800 같은 유한 상한에는 이 설정을 적용하지 않습니다. R14의 By NOTAM은 고도 미확정으로 보존합니다.
- MOA25H(HALLA)는 기존 2022년 ENR의 MOA25H 입체에 포함되어 있으나, 2026년 항공도의 구역별 하한 차이(10,000 ft AMSL / FL170)를 정확히 나눌 경계 자료가 필요합니다. 기존 원문 모델을 유지하고 부분 자료 안내를 추가했습니다.
- 자료가 부족한 16개 항목과 필요한 자료는 `sources/remaining-data.html`에서 확인합니다. P518 계열은 해안선·분계선의 완결 좌표가 없어 JS를 보완 사용하며, DOKDO 급유 회랑은 JS 독도 원형과 위치가 달라 별개로 취급합니다. 각 구역의 원문, 고도 기준, 운영 조건, 판본 날짜와 경계 보정 내용을 보존합니다. 자료 판본은 2014~2026년으로 혼재합니다.

## 공항 공역 — ENR 2.1·2.2

- 44개 공항·비행장을 등록하고, 44곳의 68개 공역 층을 표시합니다. Class B 9개, C 25개, D 34개 층입니다. 세부 도형이 여러 조각이면 각각 렌더링하며, 다각형의 내부 제외 구역을 보존합니다.
- ENR 2.2-3의 Class D ATZ 11곳(가평·양평·홍천·현리·용인·전주·영천·금왕·춘천·덕소·조치원)과 ENR 2.2-3-1의 태안·포승을 반영했습니다. 공시 좌표·반경과 P518/R35/R19 제외 조건을 적용하며, 영천은 대구 ARP 10 NM 중첩부 상한 1,000 ft AGL과 나머지 1,500 ft AGL을 나눕니다. 기존 31곳의 원문 층과 사용자 지정 모델은 유지합니다.
- 태안(한서대)은 ENR 2.2 PDF 4쪽의 좌표와 3 NM 방향별 호를 따라 Area 1 SFC–1,500 ft MSL, Area 2 SFC–1,000 ft MSL로 나눕니다. 데이터의 MSL 표기는 AMSL로 정규화하며 원문도 보존합니다. 2026년 항공도는 같은 수치를 AGL로 표시해 고도 기준 차이를 부분 자료로 안내합니다. 포승은 반경 3 NM, SFC–1,000 ft AMSL이며, 이곳도 2026년 항공도의 AGL 표기와 차이가 있어 같은 안내를 제공합니다. 목록에서 태안/TAEAN, 포승/POSEUNG으로 검색할 수 있습니다.
- 인천·김포 Class B는 하한 0·1,000·5,000 ft별로 합쳐 표시합니다. 중첩부는 낮은 하한의 층에 포함하며 각 공항의 원문 경계와 고도 정보는 보존합니다. 두 공항을 모두 켰을 때만 합쳐 표시하고, 한 공항만 선택하거나 검색하면 해당 공항의 원문 범위만 표시합니다. 합쳐진 입체에서 통합 층의 고도와 출처를 확인할 수 있습니다. 수원·오산·성무·청주 등 다른 공항의 기존 경계와 고도는 유지합니다. 연결 관계는 사용자가 마지막으로 제공한 항공정보 기준일 2026년 7월 23일 항공도로 확인했습니다.
- 공항 Class B는 보라, C는 초록, D는 분홍입니다. 기존 항공로 A(파랑)·D(주황)와 구분합니다. 혼합 B·D·E 등급의 TMA 전체를 하나의 공항 등급으로 채우지 않습니다.
- GND·SFC·AGL 기준은 원문에 보존합니다. 이 타원체 지형 모델에서는 지형 미반영 명목높이로 표시하며, AGL에 공항 표고나 지형 높이를 더한 실제 MSL 고도로 변환하지 않습니다. AMSL·FL도 원문 기준을 따로 표시합니다.
- 제주 B는 업로드된 ENR 2.2-1의 내측·중간·외측 공역을 사용합니다. 외측층의 방위별 비대칭 경계를 보존하며, 전체 원형 고리로 단순화하지 않습니다. 선택한 층의 원문 링크는 ENR 2.2 PDF를 엽니다. 자료 날짜는 업로드된 판본 그대로 표시합니다.
- 양양의 반경 5 NM 전체 원형을 유지하고, 속초에서는 양양과 겹치는 부분만 제외해 중첩부를 양양에 배정합니다. 속초 지상~2,500 ft AGL·양양 지상~3,000 ft AGL 고도와 반경은 ENR 2.1을 따릅니다. 목록의 `양양 우선` 표시와 상세창의 `중첩부 양양 배정`으로 구분합니다. P518 방향은 추가로 잘라내지 않은 사용자 지정 표시 모델입니다. 청주·성무 등 기존 경계 확인사항은 `일부` 표시 및 자료 안내에서 확인할 수 있습니다. 추가 자료가 부족한 향후 공역은 계속 `자료 필요`로 처리합니다.
- 예천 중심부 하한의 원문 `AGL` 표기는 사용자 확인 AIP 오류 정정에 따라 `GND`로 적용했습니다. 중심부와 동쪽 연장부는 GND–5,000 ft AGL, 5–10 NM 외곽층은 1,000–5,000 ft AGL로 표시합니다. 원문 PDF는 보존하고 데이터에 정정 근거를 기록했습니다.
- 공역 층 선택 패널에는 원문 범위, 기준 고도, 자료 날짜와 PDF 페이지 링크를 제공합니다. 경계 구성 방법 등 추출 메타데이터는 JSON에 보존합니다. 공항 데이터는 `airport-airspaces.json`으로 내려받을 수 있습니다.

## 항공로 자료와 적용 방법

- 재래식 항공로 18개 / 114개 구간: AIP `Lateral limits NM` 값을 전체 폭으로 적용하고, 중심선 좌우 각각 절반의 거리로 회랑을 생성합니다. 원문은 8·10·50처럼 기재하며 ± 기호가 없습니다. 폭 해석을 메타데이터에 보존했습니다.
- RNAV 항공로 36개 / 184개 구간: 사용자 지정 모델로 RNAV2 반폭 2 NM(전체 4 NM), RNAV5 반폭 5 NM(전체 10 NM)을 적용해 회랑 입체를 생성합니다. 업로드 자료의 RNAV 항공로는 모두 RNAV2이며 RNAV5 항공로를 추가로 만들지 않습니다. ENR 3.2의 공시 폭은 미기재로 보존하고, 적용 폭은 `widthSource: user-specified-model`로 구분합니다. RNAV 항법 정확도가 법적 공역 폭을 자동으로 정한다는 의미는 아닙니다. 폭이 지정되지 않은 구간만 중심선 수직 단면으로 표시합니다.
- Class A: FL200 초과~FL600와 각 항공로의 개별 하한·상한을 교집합으로 적용합니다.
- 항공로 Class D: MEA~FL200와 개별 항공로의 상한·하한을 교집합으로 적용합니다. 공항 주변 Class D 관제권은 별도의 공항 레이어에서 표시합니다.
- A586·B576의 분리된 수직 층, V547·V549의 제한된 상한, Y655·Y657·Y659 등의 특수 고도를 보존합니다. 고도 범위 사이 공백을 메우지 않습니다.
- Y655의 TOLIS–ENSUM–BONSO–ATOTI 3개 구간은 하나의 병합 칸에 공시된 FL150–FL220 및 FL430–UNL을 모두 적용합니다. 표시층은 D FL150–FL200, A FL200 초과–FL220, A FL430–FL600입니다. FL220–FL430은 비워 두며, 상위 Class G는 원문에 보존하고 기존 A·D 화면에는 그리지 않습니다. 중심선·RNAV2 반폭 2 NM·MOCA 1,500 ft는 유지합니다.
- 괄호 안 MOCA는 참고 정보로 저장하며 항공로의 하한으로 사용하지 않습니다.
- 고도는 ft에서 m로 0.3048 배율로 변환합니다. FL은 표준기압 기준을 보존하되 3D 장면에서는 1 FL=100 ft의 명목 높이로 표시합니다. 기압·지오이드·지형 보정을 적용한 실제 기하학적 고도가 아닙니다. 높이 강조 배율은 화면 표시만 변경합니다.
- 좌표는 원문 DMS를 십진 경위도로 변환합니다. 회랑은 지표면에서의 폭을 기준으로 각 구간에 생성하며, 폭이 바뀌는 구간을 별도 표시합니다.
- 항공로 원문 PDF 36쪽과 공항 공역 원문 26쪽, 구간별 출처 페이지·발효일·비고를 보존했습니다. 판본 날짜는 페이지마다 다릅니다. 최신 AIP/NOTAM 여부를 검증한 운항용 자료가 아닙니다.

Cesium 엔진은 로컬 파일로 포함합니다. 배경 지도는 OpenStreetMap 서버의 타일을 불러오므로 인터넷이 필요합니다. 높이 강조 배율을 1배로 설정하면 명목 고도에 대한 수평·수직 크기 비율을 볼 수 있습니다.

이 저장소는 브라우저 실행에 필요한 Cesium 파일을 포함하며, 중복되는 Node/ESM용 루트 `index.cjs`·`index.js` 빌드는 생략합니다.
